\## Reflection Questions



Q1: Git is a local version control tool that tracks changes in files on my computer. GitHub is a cloud platform that hosts Git repositories online. It allows collaboration, sharing and pull requests. Git works without internet, while GitHub needs internet.



Q2: The Working Directory is where I create and edit files. The Staging Area is where changes are collected using git add before committing. The Local Repository stores the committed history permanently on my computer using git commit.



Q3: git stash pop applies the saved changes and removes that entry from the stash list. git stash apply applies the changes but keeps the stash saved. So apply is useful when I want to reuse the same stash again.



Q4: git fetch only downloads new changes from the remote repository without changing my working files. git pull does fetch and then merges those changes into my current branch. Fetch is safer for checking updates first.
